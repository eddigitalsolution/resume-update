# Project Skills & Guidelines

The project agent must adhere to the custom skills defined in `.agents/skills/`:
- **`designing`**: Follow rich dark-mode glassmorphism, modern typography, gradient glows, and Framer Motion micro-animations.
- **`vercel-deploy`**: Ensure clean build verification before deployment, preserve all existing working routes and configurations without breaking changes.
- **`motion-primitives`**: Utilize Framer Motion layout transitions, smooth tabs, and interactive card entrances.
- **`ui-ux-pro-max`**: Enforce anti-AI-slop design standards, clean spacing, high-contrast typography, and accessible UI components.
